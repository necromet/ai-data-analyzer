# order_items
Items within each order.
## example
Order with 3 units: price=21.33→63.99 total, freight=15.10→45.30 total, grand total=109.29. Sum freight_value across items for order total freight.
## columns
order_id, order_item_id: Sequential item number in order.
product_id, seller_id
shipping_limit_date: Seller's deadline to hand off to carrier.
price: Item price.
freight_value: Per-item freight (split across items if multiple).
